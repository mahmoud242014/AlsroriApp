# Alsrori iOS Application

تطبيق الآيفون الرسمي لموقع **Alsrori** (https://alsrori.com).

## المميزات:
- تصميم أنيق متكامل 100% Fullscreen Edge-To-Edge بدون أي حواف
- شاشة انتظار (Splash Screen) متطابقة مع هوية الموقع بشعار Alsrori الرسمي ومؤشر تحميل متطور
- تم حذف شعار النجوم الثلاثة واستبداله باللوجو الرسمي للموقع
- دعم كامل لكاميرا واستوديو الصور والميكروفون والموقع الجغرافي
- توافق كامل مع جميع التحديثات وإضافات includes و apis الخاصة بالموقع
- جسر برمجيات JavaScript Native Bridge للتنبيهات والإشعارات الفورية
- إمكانية البناء التلقائي لملف الـ IPA مباشرة عبر GitHub Actions

## كيفية البناء عبر GitHub Actions:
1. ارفع المشروع إلى مستودع GitHub (Repository).
2. ادخل إلى تبويب **Actions**.
3. ستجد workflow باسم **Build Alsrori iOS IPA**.
4. سيعمل البناء تلقائياً مع كل Push أو يمكنك الضغط على **Run workflow**.
5. بعد انتهاء البناء (خلال 3-5 دقائق)، قم بتحميل ملف **Alsrori-iOS-IPA** مباشرة من قسم Artifacts بصيغة `.ipa`.
